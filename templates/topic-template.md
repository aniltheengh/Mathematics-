# Topic title

**Topic ID:** Assign a stable subject ID.  
**Classification:** Subject → subfield → topic.  
**Level:** State the expected background.  
**Content status:** Draft / written / needs-correction.  
**Learner mastery:** Unassessed until the learner records evidence.

Authoring template: copy into the appropriate subject directory, replace every
instruction with actual content, and add relative links to existing navigation.
Do not publish an unfilled template as a mathematics chapter.

## Prerequisites

List the minimum ideas required, link to available prerequisite pages, and give
a short diagnostic with answers. Identify planned prerequisites honestly.

## Definition

Give a precise **Definition**. State the domain and distinguish the object from
its representation. Add **Assumption** labels where a result depends on a setting.

## Intuitive explanation

Explain the idea in ordinary language. Label analogy as intuition; do not use it
as a substitute for proof.

## Mathematical notation

Define each symbol, type, unit, and convention before a formula uses it.

## Fundamental properties

State properties with hypotheses. Mark each as definition, theorem, proposition,
or a consequence of earlier results.

## Important formulas and identities

Give exact formulas with domains, exceptional cases, and links to derivations.

## Derivations and proofs

State the claim first. Show the argument, justify restricted operations, handle
edge cases, and identify any theorem assumed or cited rather than proved.

## Worked examples

Give a complete problem statement, method selection, steps, result, and an
independent check. Include units and at least one nontrivial case.

## Practice problems

Provide a recall problem, a calculation, and a reasoning or transfer question.
Separate these from solutions so self-assessment is possible.

## Answers and explanations

Write answers here or link directly to a solution set. Explain the method and
common wrong turns. Do not provide only final numbers.

## Common mistakes and misconceptions

Name specific errors, a diagnostic example, and the correction.

## Connections to other mathematics

Identify related concepts and link to their canonical pages. For unwritten
topics, link to the subject map instead of inventing a file target.

## Applications

Give a meaningful application where one exists, including a dimensioned
engineering example when appropriate. State the modeling assumptions.

## Optional computational examples

Link a small reproducible script or notebook only if it aids understanding.
Explain exact versus floating-point computation and keep the core argument in prose.

## References and recommended reading

Use verified sources, section names, stable URLs, and bibliography keys.
Distinguish sources used here from suggested future reading.

## Revision and mastery status

Keep publication status separate from personal mastery. Add self-assessment
criteria, a progress row, and a next-review date only after actual study.
