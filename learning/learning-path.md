# A suggested route back to mathematics

[Home](../README.md) · [Subject map](../CONTENTS.md) · [Revision method](revision-guide.md)

The repository folders classify mathematics; this page suggests an order for
rebuilding engineering fluency. It is a route, not a requirement to reread
everything. Attempt a diagnostic first and review only the gaps it reveals.

| Stage | Focus | Evidence before moving on |
| --- | --- | --- |
| 1 | Signed numbers, fractions, units, elementary algebra | Rearrange formulas and solve linear and quadratic equations |
| 2 | Functions, coordinate geometry, trigonometry | Interpret graphs, derive distance, handle lines and circles |
| 3 | Vectors and linear algebra | Solve systems, explain bases and projections |
| 4 | Limits, derivatives, integrals | Explain local change and accumulation with units |
| 5 | Multivariable and vector calculus | Use gradients, coordinate changes, and flux correctly |
| 6 | ODEs, transforms, numerical methods | Model a simple dynamic system and check a numerical result |
| 7 | Probability, statistics, optimization | Quantify variation and solve constrained decisions |
| 8 | PDEs and advanced analysis | Connect boundary conditions, function spaces, and approximations |
| 9 | Abstract algebra, topology, geometry, tensors | Study structures and generalizations with explicit proof habits |

Logic and proof methods run throughout all stages. Real analysis can be studied
alongside calculus when you want deeper justification; it is not merely a final
chapter after computation. Choose advanced branches according to curiosity and
applications, following their actual prerequisites.

## A concrete starting point

Read [the distance and midpoint example](../subjects/geometry/coordinate-geometry/cartesian-plane.md#distance-and-midpoint-example),
then solve [CG-01](../exercises/geometry/coordinate-geometry.md#cg-01-distance-and-midpoint)
with the answer closed. If easy, try the vertical-line and circle questions.
Use the [progress tracker](progress.csv) to record what happened.

All stages now have written reference chapters in the [master navigation](../INDEX.md).
Follow the prerequisites within each chapter; the advanced chapters give a
compact introduction with explicitly stated theorem and proof scope. The
[reading guide](../references/README.md) provides deeper primary resources.
