# Reuse and source policy

[Home](../README.md) · [Bibliography](../references/README.md)

No public distribution license has been selected for this repository. Public
visibility on GitHub alone should not be described as an open-source license.
Before sharing the work for reuse, the owner should select explicit terms for
the original prose, diagrams, notebooks, and code. An optional future choice is
a content license for prose and figures and a software license for code; this
repository does not make that choice on the owner's behalf.

The initial prose, examples, exercises, and generated figures are newly written
for this project. Reference links point to external works; those works retain
their own terms. Referencing a book does not transfer its license to these notes,
and a repository license would not grant rights to a cited third-party work.
Do not add textbook scans, copied solution manuals, or externally sourced images
without recording their source and applicable permission.
