## Three ways to use a set

For quick recall, attempt CG-01, CG-03, and CG-06. For conceptual understanding,
explain CG-05, CG-10, and CG-12 aloud before calculating. For independent
fluency, solve the full set with answers closed, then create a changed-number
version of one problem and check it by substitution.

Correct answers copied from a solution do not count as independent performance.
Record the kind of error and the smallest useful follow-up in the tracker.
