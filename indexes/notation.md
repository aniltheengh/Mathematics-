# Mathematical notation

[Home](../README.md) · [Formula index](formulas.md)

Notation is local to a topic; a symbol can have several established meanings.
Define it where used rather than assuming this table settles every context.

| Symbol | Meaning | Convention |
| --- | --- | --- |
| $\mathbb{N}$ | Natural numbers | This encyclopedia uses $\{0,1,2,\ldots\}$; state a different convention explicitly |
| $\mathbb{Z}$ | Integers | $\ldots,-2,-1,0,1,2,\ldots$ |
| $\mathbb{Q}$ | Rational numbers | Ratios of integers with nonzero denominator |
| $\mathbb{R}$ | Real numbers | Includes rational and irrational numbers |
| $\mathbb{C}$ | Complex numbers | $a+ib$ with $a,b\in\mathbb{R}$ and $i^2=-1$ |
| $\mathbb{R}^2$ | Ordered real pairs | Coordinate model of the plane |
| $\in$, $\notin$ | Is / is not an element of | A relation between an element and a set |
| $\subseteq$ | Is a subset of | Equality of sets is allowed |
| $=$, $\ne$ | Equal / unequal | Exact statements |
| $\approx$ | Approximately equal | Specify accuracy when needed |
| $\Rightarrow$, $\Leftrightarrow$ | Implies / if and only if | Logical connections, not numerical equality |
| $[a,b]$, $(a,b)$ | Closed / open interval | Context distinguishes an open interval from a point pair |
| $\lvert x\rvert$ | Absolute value of real $x$ | Nonnegative magnitude |
| $\sqrt{x}$ | Principal square root | Nonnegative for real $x\ge0$ |
| $\Delta x$ | Change in $x$ | Final minus initial |
| $d(A,B)$ | Distance | Depends on the specified geometric setting |
| $\mathbf v$ | Vector | Distinguish a vector from a coordinate point when relevant |
| $\lVert\mathbf v\rVert$ | Norm | State which norm; Euclidean unless specified locally |
| $\mathbf u\cdot\mathbf v$ | Euclidean dot product | Sum of component products in an orthonormal frame |

## Coordinate geometry conventions

$x$ is horizontal and $y$ vertical in the chapter's diagrams, and both axes use
the same length scale. Points use capital letters; coordinates and line
coefficients are real scalars. Use $\beta$ for a vertical intercept to avoid
confusing it with coefficient $b$ in $ax+by+c=0$.

A prime such as $x'$ may later indicate a new coordinate or a derivative; define
the meaning before using it. Do not mix degrees and radians without conversion.
Physical coordinate values carry the specified unit. Function graphs with unlike
axis units do not automatically represent geometric lengths.
